# One-page PRD template

Fill in all eight boxes before you open an editor. Boxes 1, 2, 3, 5, and 6 should mostly be pasted from earlier design work; boxes 4, 7, and 8 are new writing. Keep every box to a few lines — if a box needs a second page, the scope is already too big.

## 1. One-liner

_The It/For/So solution statement, verbatim._

## 2. User

_One sentence describing the specific person, uncomfortably narrow._

## 3. Problem evidence

_Two or three bullet points of proof: interview quotes, competitor gap, waitlist count._

## 4. Core action

_The single loop of value — input, process, output — in one sentence._

## 5. The five nodes

_Landing, Auth, Home, Input, Output, each described in one line._

## 6. Stack commitment

_The five-blank stack commitment, pasted verbatim._

## 7. Out of scope

_Every feature you are explicitly refusing to build in this version. Include the ones you're most excited about — writing them down is what makes them easy to not build today._

## 8. Done when

_The observable conditions that mean this version is finished._
